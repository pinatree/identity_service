# Конфигурация Identity Service

Конфигурация собирается из трёх источников **в порядке возрастания приоритета**:

1. **Значения по умолчанию** — сервис работает вообще без файла конфигурации;
2. **Файл `config.json`** — должен лежать в рабочей директории, из которой
   запущен процесс;
3. **Переменные окружения** — переопределяют значения из файла.

```text
дефолты  <  config.json  <  переменные окружения
```

## Значения по умолчанию

| Параметр | Значение | Комментарий                                  |
|----------|----------|----------------------------------------------|
| `port`   | `8080`   | TCP-порт, на котором слушает сервер          |
| `name`   | `identity-service` | Имя сервиса (отдаётся в `/health`) |
| `version`| `1.0.0`  | Версия сборки                                |
| `token_ttl` | `300` | Время жизни токена, секунды (5 минут)         |
| `db_connection` | `postgres://app:secret@localhost:5432/appdb?sslmode=disable` | Строка подключения к БД (PostgreSQL) |

## Файл config.json

Файл **необязателен** и **не создаётся автоматически**. Если его нет —
используются значения по умолчанию. Формат — JSON:

```json
{
  "port": "8080",
  "name": "identity-service",
  "version": "1.0.0",
  "token_ttl": 300,
  "db_connection": "postgres://app:secret@localhost:5432/appdb?sslmode=disable"
}
```

### Поля

| Поле        | Тип    | По умолчанию    | Описание                                 |
|-------------|--------|-----------------|------------------------------------------|
| `port`      | string | `"8080"`        | Порт сервера, строка без префикса `:`            |
| `name`      | string | `"identity-service"` | Имя сервиса, попадает в `/health`            |
| `version`   | string | версия сборки   | Версия, отдаётся в `/version`                     |
| `token_ttl` | int    | `300`           | Время жизни токена в секундах; `<= 0` игнорируется |
| `db_connection` | string | `"postgres://app:secret@localhost:5432/appdb?sslmode=disable"` | Строка подключения к PostgreSQL (URL-формат); пустая строка игнорируется |

Пустые значения полей (`""`) игнорируются — для них остаются значения
по умолчанию (или из переменной окружения).

## Переменные окружения

| Переменная     | Тип    | Описание                                         |
|----------------|--------|--------------------------------------------------|
| `PORT`         | string | Порт сервера                                     |
| `NAME`         | string | Имя сервиса                                      |
| `VERSION`      | string | Версия сервиса                                   |
| `TOKEN_TTL`    | int    | Время жизни токена, секунды (должно быть `> 0`) |
| `DB_CONNECTION` | string | Строка подключения к БД                          |

Пример:

```bash
PORT=9000 TOKEN_TTL=60 DB_CONNECTION=postgres://user:pass@localhost/counter ./identity-service
```

Некорректное значение `TOKEN_TTL` (не число или `<= 0`) **молча игнорируется** —
остаётся значение из файла или по умолчанию.

## Ошибки конфигурации

Ошибки возвращаются и завершают процесс с ненулевым кодом только в двух случаях:

| Ситуация                      | Как проявляется                        |
|-------------------------------|----------------------------------------|
| Файл есть, но не читается     | Сервис не запускается, ошибка в лог    |
| Файл есть, но не валидный JSON| Сервис не запускается, ошибка в лог    |

Самый безопасный способ проверить конфигурацию — просто запустить сервис
и посмотреть лог; либо прогнать тесты пакета:

```bash
make test
go test -race ./internal/config/...
```

## Примеры

### 1. Запуск вообще без файла

```bash
./identity-service
# Сервер слушает :8080, name=identity-service
```

### 2. Файл, частично переопределяющий дефолты

```json
{ "port": "3000", "token_ttl": 120 }
```

### 3. Полная конфигурация

```json
{
  "port": "8080",
  "name": "my-counter",
  "version": "2.1.0",
  "token_ttl": 900,
  "db_connection": "postgres://user:pass@localhost:5432/mydb"
}
```

### 4. Переменные окружения поверх файла

```bash
PORT=9000 NAME=prod-counter ./identity-service
```

## Изменения поведения (важно для миграции)

По сравнению с ранними версиями сервиса:

- **файл больше не создаётся автоматически** и не требуется для запуска;
- **нет `os.Exit` внутри пакета** — ошибки возвращаются вызывающему коду;
- **пустой `config.json` валиден** — сервис просто использует дефолты;
- **приоритет:** окружение > файл > дефолты.
